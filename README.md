# 抢票排队监控助手

> ⚠️ 本扩展为个人开发的非官方工具，与 NOL / Interpark 等任何票务平台**无隶属、授权或合作关系**。

一款 Chrome / Edge 浏览器扩展，用于监控抢票网站排队进度。当排队前方人数降至你设置的阈值、页面出现异常弹窗，或成功进入购票/选座页面时，自动通过飞书通知、浏览器系统通知，并在本地播放铃声提醒。

---

## 功能特性

- **自动识别排队页面**：检测到 `My waiting order` / `我的等候顺位` 等排队元素后开始监控。
- **实时提取排队数据**：包括当前顺位、前方人数、等候总人数、预订率。
- **阈值提醒**：设置“前方 ≤ N 人时提醒”，到达阈值立即通过飞书 / 铃声 / 系统通知提醒。
- **异常弹窗检测**：自动识别“长时间内没有任何回应，此订单已被取消”等异常，立即提醒。
- **进入购票页提醒**：排队完成、页面跳转至选座/购票页时通知。
- **多通道提醒（可任意组合）**：
  - 飞书群机器人通知（需自备 Webhook）
  - 浏览器本地铃声（Web Audio）
  - 浏览器系统通知
  - 「起床铃」循环闹钟（适合半夜叫醒熟睡的人）
- **防刷屏机制**：同一事件有冷却时间，避免连续重复通知。

## 安装步骤

### 1. 准备飞书群机器人 Webhook（用于飞书通知）

1. 在飞书电脑端创建一个只有你自己的群（或个人群）
2. 群设置 → 群机器人 → 添加「自定义机器人」
3. 复制该机器人的 **Webhook 地址**（形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxxx`）
4. 将地址粘贴到插件弹窗的「飞书机器人 Webhook 地址」一栏



### 2. 安装浏览器扩展



#### Chrome / Edge

1. 打开浏览器，进入扩展管理页面：
  - Chrome：`chrome://extensions/`
  - Edge：`edge://extensions/`
2. 开启右上角/左下角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目所在文件夹 nol-queue-monitor-main
5. 安装成功后，浏览器工具栏会出现蓝色「Q」图标



### 3. 配置插件

1. 点击浏览器工具栏的「Q」图标，打开插件弹窗
2. 填入飞书 Webhook 地址
3. 设置提醒阈值（例如：前方人数 ≤ 1000 时提醒）
4. 勾选需要的提醒方式（飞书通知 / 浏览器铃声 / 浏览器通知，可选起床铃）
5. 点击「保存设置」
6. 点击「测试」确认飞书能收到消息

## 使用方法

1. 在浏览器中打开 NOL World 抢票页面并进入排队队列。
2. 保持浏览器窗口打开（可以最小化，但不要关闭）。
3. 插件会自动检测排队页面并开始监控。
4. 当满足以下任一条件时，你会收到飞书通知 + 浏览器铃声 + 系统通知：
  - 前方排队人数 ≤ 阈值
  - 页面弹出“订单已被取消”等异常
  - 排队完成，进入选座/购票页面

## 常见问题



### Q1：为什么测试发送成功，但飞书没收到消息？

- 确认粘贴的飞书 Webhook 地址完整且正确（形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxxx`）。
- 确认该自定义机器人未被停用、且仍在该飞书群中。
- 在飞书客户端检查是否对群消息开启了通知（群通知可能被折叠或设为免打扰）。



### Q2：为什么没有播放铃声？

- 确认插件设置中开启了「播放铃声」。
- 浏览器标签页需要保持激活或至少未被完全静音。
- 系统音量需要打开。



### Q3：为什么没有检测到排队页面？

- 确认当前页面 URL 包含 `nol.com` 或 `interpark.com`（NOL World 的排队实际在 tickets.interpark.com 上）。
- 如果安装扩展时已经在排队页，**无需刷新**（刷新会重置排队），直接打开插件弹窗，它会自动注入监控脚本。
- 排队页面加载可能需要几秒，插件会自动重试。
- 打开插件弹窗查看当前状态。



### Q4：收到通知后还需要手动操作吗？

- 需要。插件只负责提醒，不会自动帮你抢票或点击按钮。
- 收到提醒后请尽快回到浏览器页面继续操作。



### Q5：可以关掉浏览器吗？

- 不可以。浏览器插件必须在浏览器运行时才能工作。
- 建议将浏览器窗口最小化，但不要关闭。
